# Lovable prototype — reference only, NOT a design to follow

These are screenshots and the handover from an earlier prototype Daniel built in Lovable.
Use them for exactly one thing: **a checklist of features and coach workflows that must be covered** (builder, calendar day/week/month, templates, analytics, exercise bank, live load panel).

Do NOT copy its layout, visual design, component choices, data model or calculation logic.
Known weaknesses: generic form-heavy builder, a single invented "load index", a polluted exercise bank, no multi-coach/gym model.

The target is a product several levels above this in quality, speed and coaching depth.
Design is decided from first principles for how coaches actually program (keyboard-first, dense but calm, numbers that are honest about uncertainty) — see the design direction in docs/PLAN-step-4.md.
