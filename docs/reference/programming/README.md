- `afrek-2024.xlsx` — Afrek Functional Fitness, full year 2024 (504 workouts). One sheet per month, one row per day; col A day focus / holidays, B day, C weekday, then one column per program (KRAFTUR & ÚTHALD, STYRKUR, ÞREK, LIÐLEIKI).

Use these to test the parser (Paste) and the future Program import, and to find gaps in the exercise library.

**Important (Daniel, 2026-10-23):** this is ONE gym's writing style, not an industry standard. Support it, but never overfit the parser to it: every rule must also work for other common whiteboard styles. Private: do not publish or share outside this repo.
