# Exercise library coverage

Generated by `scripts/library-coverage.ts` from a year of a gym's real programming (Afrek 2024, one sheet per month,
one cell per workout), read by the paste parser (version 3). The spreadsheet stays on the machine it
was run on: this report holds exercise words and counts only, never a workout. One gym's words are one gym's
style: the proposals below use the names most gyms write, and a gym's own phrasing becomes its own alias on import.

**Nothing here is in the library yet.** The proposed exercises, aliases and generic words wait for Daniel's approval
(BACKLOG "Exercise library"); approved ones move into `src/lib/library/core-exercises.ts` with one migration.

With the proposals, some lines that were notes (an unknown word with no amount, as a station) become exercises:
so the mentions grow.

"Unknown" includes words that are not exercises at all ("each", "rest", "stations"): what the parser still
misreads, listed under "Parser follow-ups". A coach picks an unknown exercise once per import; an owner can keep
the answer as the gym's name for it.
